# 🧮 Projeto Calculadora em Java

![Java](https://img.shields.io/badge/java-%23ED8B00.svg?style=for-the-badge&logo=openjdk&logoColor=white)
![Status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-green?style=for-the-badge)

Um projeto simples e intuitivo de uma calculadora construída em **Java**, desenvolvida para executar operações matemáticas básicas diretamente no terminal. Este projeto é ideal para demonstrar fundamentos da linguagem, como estruturas de decisão, leitura de dados do teclado e componentização de código (métodos).

## 🚀 Funcionalidades

A calculadora é capaz de realizar as seguintes operações matemáticas:
- [x] Adição (+)
- [x] Subtração (-)
- [x] Multiplicação (*)
- [x] Divisão (/)
- [x] Tratamento básico contra divisão por zero.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando apenas o núcleo do Java, sem necessidade de bibliotecas externas:
* **Linguagem:** Java (JDK 8 ou superior)
* **Entrada de Dados:** `java.util.Scanner`
* **Estrutura de Controle:** `switch-case` para o menu de operações.
* **Paradigma:** Orientação a Objetos básica e uso de Métodos/Funções para evitar repetição de código.
